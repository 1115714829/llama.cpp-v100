## 引擎

## 服务 `qwen27b-v100.service`(user 级,已 enable,`Linger=yes` 开机自启)

```ini
[Unit]
Description=Qwen3.8-27B (V100-fork 2.0.0) dual-channel 64K + VL, dual V100 tensor-split NVLink, port 8082
After=network-online.target
Wants=network-online.target

[Service]
Type=simple
ExecStart=/home/dxc/llama-v100-test/repo-wt-2.0.0/build-2.0.0/bin/llama-server \
    -m /home/dxc/models/Qwen3.8-27B/Qwen3.8-27B-Q4_K_M.gguf \
    -ngl 999 \
    --split-mode tensor \
    --tensor-split 1,1 \
    -c 131072 -np 2 \
    -fa on -ctk q4_0 -ctv q4_0 -b 2048 -ub 2048 \
    --model-draft /home/dxc/models/Qwen3.8-27B-DFlash2-GGUF/Qwen3.8-27B-DFlash2-Q4_K_M.gguf \
    --spec-type draft-dflash --spec-draft-n-max 7 \
    --mmproj /home/dxc/models/Qwen3.8-27B/mmproj-F16.gguf \
    --alias qwen3.8-27b \
    --host 127.0.0.1 --port 8082 --metrics
# NVLink P2P allreduce (system NCCL stack is broken on this driver; internal goes around it)
Environment=GGML_CUDA_ALLREDUCE=internal
Environment=CUDA_VISIBLE_DEVICES=0,1
Environment=CUDA_DEVICE_ORDER=PCI_BUS_ID
Environment=LD_LIBRARY_PATH=/home/dxc/llama-v100-test/repo-wt-2.0.0/build-2.0.0/bin
WorkingDirectory=/home/dxc/models/Qwen3.8-27B
Restart=on-failure
RestartSec=15
TimeoutStartSec=600
StandardOutput=journal
StandardError=journal

[Install]
WantedBy=default.target
```

要点:

- `-c 131072 -np 2` = 每 slot 64K 上下文 × 2 并发通道;KV 全 q4_0,超出显存部分自动落 RAM(121 G 充足)
- 端口 `127.0.0.1:8082`;LAN 侧由 `~/.hermes/scripts/lan_forward_8080_8082.py` 转发到 `192.168.8.96:8082`
- 冷启动 ~145 s(16 G 主模型 + 1.1 G draft + mmproj)
- OpenAI 兼容 API:`POST /v1/chat/completions`;stream 时思考流在 `delta.reasoning_content`,正文在 `delta.content`
- 管理:`systemctl --user {start|stop|restart|enable} qwen27b-v100`;日志 `journalctl --user -u qwen27b-v100 -f`

## 坑

1. **NCCL 坏了**:`GGML_CUDA_ALLREDUCE=internal` 必须加——该 driver 上系统 NCCL 栈不可用,走库内 P2P allreduce 绕过 NVLink
2. **默认开思考**:chat template 默认 reasoning-preserve,短任务会先流几百 token 思考;prompt 末尾加 `/no_think` 跳过
3. **端口史**:2026-10-25 曾因 8082 被 Strata 占用,用 drop-in(`qwen27b-v100.service.d/port-8083.conf`)放 8083;10-26 Strata 退役后 drop-in 已删,回到 8082
4. **显存账**:Q4_K_M 16 G 权重 tensor-split 后每卡 ~8 G,余 ~7 G 给 KV/计算 buffer;要更大并发/上下文,先降 `-np` 或 `-c`,再考虑 KV 落 RAM 的速度代价
5. 本地 main repo 曾长期 detached 在 2.0.0 build commit,操作前先 `git fetch` + 切 master,别在 build commit 上提交
